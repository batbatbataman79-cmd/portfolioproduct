## Жёсткие технические правила

1. Только **HTML5 + CSS3 + vanilla JS**. Никаких фреймворков, сборщиков, npm, зависимостей.
2. **Все пути относительные.** С главной: `css/style.css`, `assets/...`, `cases/x.html`. Со страниц в `cases/` и `blog/`: `../css/style.css`, `../index.html`, `../assets/...`.
3. Сайт должен открываться двойным кликом по `index.html` локально и работать на GitHub Pages без настройки. Файл `.nojekyll` в корне не удалять.
4. Один общий файл стилей `css/style.css` и один скрипт `js/main.js` на весь сайт.
5. Шрифты — только Google Fonts через `<link>`: **Inter Tight** (заголовки, 300–700) и **Inter** (текст, 400–600).
6. В коде оставлять понятные русские комментарии: где менять текст и картинки.

## Генераторы — важно

Страницы в `cases/` и `blog/` **сгенерированы**. Если править HTML руками, следующий запуск генератора перезапишет правки. Правильный путь — менять данные в генераторе и перезапускать:

```bash
python3 tools/gen_all.py    # все cases/<slug>.html + cases/index.html (данные — списки TILDA и EXTRA в файле)
python3 tools/gen_blog.py   # все blog/<slug>.html из tools/articles/*.txt
```

- **Новый кейс:** добавить `dict(...)` в `TILDA` или `EXTRA` в `tools/gen_all.py` (поля: slug, title, kind, site, lead, f — тройка «проблема → решение → результат», ctx, prob, hyp, did, res, out; опционально cover). Картинки положить в `assets/cases/<slug>/01.jpg, 02.jpg…`. Ссылка «Посмотреть сайт» показывается, только если `site` не `None`.
- **Новая статья:** создать `tools/articles/NN.txt`. Разметка: строки `@slug`, `@rubric`, `@title`, `@lead`, `@seo_title`, `@seo_desc`, `@card`; затем абзацы через пустую строку; `## Пункт оглавления | Полный заголовок H2`; `### H3`; строки `- ` — список (`**жирный**` работает); `> ` — выделенный вывод; `[[slug|текст]]` — ссылка на другую статью. Порядок статей = порядок файлов, «Следующая статья» идёт по кругу.
- Карточки статей для главной генератор кладёт в `tools/blog_cards.html` — их нужно вручную вставить в `index.html`, блок `#journal`, внутрь `.grid-3`.
- Слайдер кейсов на главной (`#portfolio`, `#cases-track`) правится **вручную** в `index.html`. Сейчас там 5 последних кейсов: map, tureckaya, enduro, spstudio, alex-krown.

## Дизайн-система

Токены в `:root` файла `css/style.css`:

| Токен | Значение |
|---|---|
| `--bg` | `#F3F3F3` — фон всего сайта |
| `--text` | `#1A1A1A` |
| `--accent` | `#FF6B1A` — оранжевый: hover кнопок, маркеры, активные состояния |
| `--muted` | `#6B6B6B` |
| `--dark` / `--on-dark` | `#1A1A1A` / `#F3F3F3` — баннер, футер, CTA |
| `--card` | `#FFFFFF` |
| `--container` | 1200px, отступ между секциями `--section` 120px (80px на мобильном) |

Стиль: минимализм, много воздуха, крупные тонкие заголовки (Inter Tight 300–400, отрицательный letter-spacing), белые карточки со скруглением 16px, подчёркнутые ссылки со стрелкой ↗ (`.link-arrow`), кнопки-«таблетки» (`.btn`, hover — фон акцентный, `transition: 0.3s`).

Адаптив: брейкпоинты 1100, 1024, 768, 480/560px. Горизонтального скролла страницы быть не должно.

Анимации: класс `.reveal` (+ `data-delay="100"`) — fade-in при скролле через IntersectionObserver в `js/main.js`. Там же: линия под шапкой при скролле, кнопки слайдера, текущий год, подсветка активного пункта оглавления в статьях.

Фото в hero: фон портрета выровнен ровно в `#F3F3F3` и растворяется снизу маской. При замене фото фон нужно привести к `#F3F3F3`, иначе станет виден прямоугольник.
